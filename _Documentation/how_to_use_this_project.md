### *A Practical Guide for Officers, Analysts, and Future Council Leaders*

This document explains how to navigate, operate, and extend the Knights of Columbus Council 16207 analytics system. It is designed for future officers, collaborators, and anyone reviewing the project for technical or operational understanding.

# 1. Purpose of This Project

This project provides a **data‑driven operating system** for Council 16207. It helps officers:

- Track member engagement  
- Monitor volunteer hours  
- Evaluate event performance  
- Identify activation and retention patterns  
- Plan programming based on evidence  
- Ensure continuity in a high‑turnover college environment  

The system is intentionally simple, portable, and built in Google Sheets so future officers can maintain it without technical expertise.

# 3. Using the Event Tracker (Google Sheets)

The Event Tracker is the core of the system. It contains:

- Event name, date, and type  
- Participating members  
- Volunteer and fraternal hours  
- Event cost and return  
- Notes and impact metrics  

### How to update it:
1. Open the Google Form linked to the sheet.  
2. Submit event details immediately after each event.  
3. Ensure participant names are spelled consistently.  
4. Officers should periodically review entries for accuracy.

### What happens automatically:
- A Google Apps Script parses participant lists.  
- A normalized member‑level table is generated.  
- KPIs update automatically across dashboards.  

No manual formula editing is required.

# 4. Understanding the Dashboards

The dashboards are designed to give officers **instant visibility** into council health.

## AMPM Dashboard
Shows:
- Active members per month  
- New activations  
- Activation sources (event types)  
- % active in last 90 days  
- Participation distribution  

Use this dashboard to evaluate **engagement and recruitment**.

## Retention Dashboard
Shows:
- Tenure distribution  
- Time since last event  
- 30‑day and 90‑day retention  
- Churn and reactivation rates  

Use this dashboard to evaluate **continuity and risk**.

## Program Mix Dashboard
Shows:
- Events per pillar  
- Hours accumulated per pillar  
- Individuals served  
- Member participation profiles  

Use this dashboard to evaluate **program balance** (breadth vs. depth).

# 5. How to Interpret the Insights

The system is built around several key analytical concepts:

### **Breadth (Charity Events)**
- Attract the most unique members  
- Drive the majority of activations  
- Best for recruiting and reactivating members  

### **Depth (Faith Events)**
- Generate the most hours per event  
- Strengthen commitment among active members  
- Best for retention and leadership development  

### **Continuity Risk**
- 75% of active members leave within 2 years  
- Without new activations, AMPM collapses  
- Dormant members with 3–4 years remaining are the highest‑value targets  

### **Operational Efficiency**
- 92% of hours are service/faith, not overhead  
- Tracking hours increases visibility and motivation  

These insights guide the recommended actions.

# 6. Implementing the Recommended Actions

### 1. Expand Service Programming
- Add 1–2 additional service events per month  
- Target a 10–15% increase in AMPM  
- Use service events as the first touchpoint for new and dormant members  

### 2. Target Dormant & Unactivated Members
- Aim to activate 1 dormant/unactivated member per month  
- Pair each target with an active “buddy”  
- Invite them first to charity events  

### 3. Continuity Planning
- Reintroduce “Knights of the Round Table” onboarding  
- Document officer workflows  
- Identify 3–5 members with 2+ years remaining for leadership roles  

### 4. Balance Breadth + Depth
- Maintain a 3:1 charity‑to‑faith ratio  
- Use charity for activation; faith for commitment  
- Target 45% 30‑day retention

# 7. How Future Officers Should Maintain the System

To keep the system running smoothly:

### Weekly
- Review new event entries  
- Check dashboards for anomalies  
- Follow up with dormant members  

### Monthly
- Review AMPM and retention metrics  
- Evaluate program mix  
- Adjust event planning accordingly  

### Semesterly
- Conduct a performance review  
- Update goals and KPIs  
- Document officer transitions  

### Yearly
- Archive the sheet  
- Duplicate the template for the next Colombian Year  
- Train new officers using this document
